
# Sales Prediction Using Python

## Project Overview
This project focuses on predicting product sales based on advertising expenditure across three media channels: TV, Radio, and Newspaper.

## Objective
To analyse the relationship between advertising spending and sales and build regression models to predict product sales.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Dataset
The Advertising dataset contains the following columns:
- TV
- Radio
- Newspaper
- Sales

## Project Workflow
1. Data Loading
2. Exploratory Data Analysis
3. Data Visualization
4. Feature Selection
5. Train-Test Split
6. Linear Regression
7. Random Forest Regression
8. Model Evaluation
9. Model Comparison
10. Residual Analysis
11. Feature Importance

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## Files
- Sales_Prediction.ipynb – Google Colab notebook containing the complete project.
- advertising.csv – Dataset used for analysis.
